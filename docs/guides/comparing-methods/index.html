Comparing methods

A walk-forward harness that needs only numpy.

Run a comparison

compare trades each estimator forward through a panel of returns. At each period it earns the return on the weights already held and then updates the estimator with that period's data.

from allocation import SchurComplementary, MinimumVariance, TurnoverPenalty
from allocation.backtest import compare, format_table, make_panel

panel = make_panel()             # synthetic; or any (n_obs, n_assets) array
rows = compare({
    "schur":       lambda: SchurComplementary(gamma=0.5),
    "schur, damped": lambda: TurnoverPenalty(SchurComplementary(gamma=0.5), cost=3.0),
    "minvar":      lambda: MinimumVariance(shrinkage=0.1),
}, panel, warmup=60, cost_bps=10.0)
print(format_table(rows))

Each entry is a function that builds a fresh estimator. The table reports:

ColumnMeaning
SharpeAnnualized out-of-sample Sharpe ratio, before costs.
netSharpe ratio after charging cost_bps on every unit traded.
volAnnualized volatility.
turnoverMean fraction of the book traded per period, including the trades that restore the targets after prices move.
max_wLargest single weight, on average.
eff_NEffective number of holdings.

The rows returned by compare also carry expected shortfall at 95% and 99%, maximum drawdown and the Sortino ratio.

No data ships with the package. load_returns_csv(path_or_url) reads a numeric panel from a CSV file.

If the estimators are fitted on log returns, pass simple returns as pnl_returns to walk_forward, since a weighted sum of log returns is not a portfolio return.

Many universes at once

A single backtest depends on which assets and which period you chose. compare_random_subsets repeats the comparison on random subsets of the assets, and optionally random windows of time, and reports each method's mean and standard deviation of net Sharpe, mean turnover, and the fraction of trials it won.

from allocation.backtest import compare_random_subsets

compare_random_subsets(factories, returns, k=50, window=500, n_trials=100)

Are the short positions earning anything?

A signed method such as minimum variance may hold short positions that are only estimation noise. negative_weight_diagnostic walks the method forward, then re-prices the same path of weights with the shorts removed, and compares.

from allocation import MinimumVariance, negative_weight_diagnostic

d = negative_weight_diagnostic(lambda: MinimumVariance(shrinkage=0.1), returns)
d["sharpe_gain_from_shorts"]   # net Sharpe with shorts minus net Sharpe without
d["sign_flip_rate"]            # how often a shorted asset changes sign
d["shorts_needed"]             # True only if the gain is clear and the shorts are stable
