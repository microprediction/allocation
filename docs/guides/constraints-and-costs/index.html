Constraints and trading costs

Two wrappers that go around any estimator.

Position bounds and group caps

BoxConstrained imposes a lower and upper bound on each weight and an upper bound on the total weight of each group, such as a sector. Groups must not overlap.

from allocation import BoxConstrained, MinimumVariance

est = BoxConstrained(
    MinimumVariance(shrinkage=0.1),
    lower=0.0, upper=0.10,                    # long-only, at most 10% per asset
    groups=[[0, 1, 2], [3, 4]], group_caps=[0.30, 0.25],
)
est.fit(returns).weights_

The usual way to impose bounds is to project onto them, which gives weights a kink each time a bound starts or stops binding. This wrapper uses a logarithmic barrier instead. It returns the point closest to the unconstrained weights after a penalty that grows without limit at each bound.

  • The result satisfies the constraints for any barrier strength tau.
  • A smaller tau (default 0.0001) lets weights sit closer to a bound.
  • The result varies smoothly with the unconstrained weights.
  • Constraints that cannot all hold raise ValueError.

StreamingBoxConstrained takes bounds as numbers or dicts keyed by asset, groups as a dict from asset to group label, and group_caps as a dict from label to cap.

A turnover penalty

TurnoverPenalty charges a quadratic cost for moving away from the weights currently held. With cost λ the result is a blend of the estimator's new target and the previous weights:

wt = α wtarget + (1 − α) wt−1,   α = 1 / (1 + λ)

Each step therefore covers a fraction α of the distance to the target. The weights still sum to one.

from allocation import TurnoverPenalty, SchurComplementary

est = TurnoverPenalty(SchurComplementary(gamma=0.5), cost=3.0)   # a quarter of each step
est.fit(returns)
est.partial_fit(new_rows)
est.alpha_          # 0.25

StreamingTurnoverPenalty does the same for the streaming classes. An asset that has just entered is taken at its target weight, since there is no earlier weight to blend with.

Combining them

The wrappers nest. Apply the turnover penalty first and the bounds last, so the bounds hold on the weights you trade.

BoxConstrained(TurnoverPenalty(MinimumVariance(shrinkage=0.1), cost=2.0), lower=0.0, upper=0.10)
