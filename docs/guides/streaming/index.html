Streaming and changing universes

Two interfaces, the covariance behind them, and assets that enter and leave.

The batch interface

Every estimator follows scikit-learn and skfolio conventions. returns is an array with one row per period and one column per asset.

from allocation import SchurComplementary

est = SchurComplementary(gamma=0.5)
est.fit(returns)             # estimate from scratch
est.weights_                 # one weight per column, summing to one

est.partial_fit(new_rows)    # update with new observations
est.predict(returns)         # portfolio return per row
est.score(returns)           # per-period Sharpe ratio

partial_fit updates the covariance estimate and then updates the weights from their previous state. It does not start again. That is what keeps turnover low.

With pip install allocation[skfolio], est.to_portfolio(returns) returns a skfolio Portfolio for use with skfolio's metrics and cross-validation.

The streaming interface

The batch classes assume the same assets in every row. The Streaming… classes do not. Each observation is a dict from asset identifier to return, as in river, and the set of keys may change from one observation to the next.

from allocation import StreamingSchur

est = StreamingSchur(gamma=0.5)
for x in stream:                 # x = {"AAPL": 0.012, "MSFT": -0.004, ...}
    est.learn_one(x)             # assets may appear or disappear
    w = est.predict_one()        # {"AAPL": 0.31, "MSFT": 0.22, ...}

State is kept per asset. An asset that stays keeps its state and its weight moves smoothly. A new asset is given weight only after it has been seen min_obs times (default 20). An asset that leaves drops out and the rest are renormalized.

Covariance estimators

The batch estimators read a covariance from a separate object, which can be replaced.

EstimatorWhat it estimates
EwmaCovariance(halflife=60)Exponentially weighted mean and covariance. The default.
DownsideSemicovariance(halflife=60, threshold=None)Covariance of the returns' shortfalls below a threshold. The threshold is the running mean, or a fixed number such as 0. Assets that fall together and rise independently show a high downside correlation.
Your ownAny object with partial_fit(X) and a covariance_ attribute, for example an estimator from precise.
from allocation import RiskParity, DownsideSemicovariance

RiskParity(covariance_estimator=DownsideSemicovariance(threshold=0.0)).fit(returns).weights_

The streaming classes use KeyedEwmaCovariance, the same estimate held in a dict keyed by asset.
