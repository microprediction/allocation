Hierarchical risk parity

Recursive bisection over a spectral ordering of the assets.

Batch
HierarchicalRiskParity
Streaming
StreamingHRP
Weights
Long-only, sum to one
Covariance inverse
None

Order the assets so that similar ones sit together. Split the order in two, divide the budget between the halves in inverse proportion to their variances, and repeat inside each half.

What it does

This is the method of López de Prado (2016) with one change. The original takes the asset order from a dendrogram, which can rearrange abruptly when the covariance moves a little. This estimator orders the assets along the Fiedler vector of the correlation graph, which rearranges only when two coordinates cross.

Because the order differs, the weights differ from those of a dendrogram-based implementation on the same data.

It is the gamma=0 case of Schur-complementary and the near end of the Schur bridge hrp_to_min_variance.

Use

from allocation import HierarchicalRiskParity

est = HierarchicalRiskParity().fit(returns)
est.weights_
est.order_          # the asset order used for bisection
