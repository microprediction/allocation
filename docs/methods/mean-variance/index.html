Mean–variance

The tangency portfolio for a vector of expected returns.

Batch
MeanVariance
Streaming
StreamingMeanVariance
Weights
Signed, sum to one
Covariance inverse
Yes

w ∝ Σ−1μ

The Markowitz tangency portfolio, with short positions allowed. The weights are scaled to sum to one.

What to watch for

The formula is smooth in both inputs. The difficulty is the expected-return vector μ, which is hard to estimate. The weights are only as stable as whatever supplies it.

If expected_returns is not given, the estimator uses the running exponentially weighted mean of the returns. That keeps the estimator self-contained. It is not a forecast worth trading on.

Use

from allocation import MeanVariance

MeanVariance(expected_returns=mu, shrinkage=0.1).fit(returns).weights_
MeanVariance(shrinkage=0.1).fit(returns).weights_      # mu from the running mean
