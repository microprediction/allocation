Minimum variance

The lowest-variance portfolio, in closed form.

Batch
MinimumVariance, FactorMinimumVariance
Streaming
StreamingMinimumVariance
Weights
Signed, sum to one
Covariance inverse
Yes

w ∝ Σ−11

The weights that minimize portfolio variance when short positions are allowed. They sum to one and can be negative.

What to watch for

The formula is a smooth function of the covariance, so the weights move only as the covariance estimate moves. Two things spoil that.

Conditioning. When the covariance is close to singular its inverse is large and a small change in the estimate swings the weights. shrinkage blends the covariance toward a scaled identity before inverting. At shrinkage=1 the result is equal weight.

More assets than observations. The covariance is then rank-deficient and the minimum-variance portfolio is not defined. The estimator returns a least-squares solution and sets singular_ to True. With strict=True it raises.

Use

from allocation import MinimumVariance

est = MinimumVariance(shrinkage=0.1).fit(returns)
est.weights_        # may contain negative entries
est.singular_       # True if the covariance could not be inverted reliably

Large universes

FactorMinimumVariance writes the covariance as a factor model, Σ = BBT + diag(ψ), and inverts it with the Woodbury identity. The cost is linear in the number of assets. A floor on the idiosyncratic variances bounds the condition number, so the inverse always exists.

from allocation import FactorMinimumVariance

FactorMinimumVariance(factors=5).fit(returns).weights_

If you need long-only weights

A long-only minimum-variance program is not provided. Its solution has a kink each time an asset reaches zero weight, which produces turnover. The alternatives here:

  • Schur bridge with long_only=True, which approaches minimum variance from hierarchical risk parity and stops before any weight turns negative.
  • BoxConstrained around MinimumVariance, which applies bounds smoothly.
  • negative_weight_diagnostic, which tests whether the short positions earn anything out of sample.

Parameters

ParameterDefaultMeaning

covariance_estimatorNoneAny online estimator with partial_fit and covariance_. None uses an exponentially weighted covariance.

FactorMinimumVariance takes factors (default 5) and floor (default 0.001, as a fraction of mean variance). A covariance estimator that exposes loadings_ and idiosyncratic_ is used directly.
