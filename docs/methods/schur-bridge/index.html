Schur bridge

One dial, or two, from a hierarchical heuristic to an optimizer, exact at both ends.

Batch
SchurBridge
Streaming
StreamingSchurBridge
Weights
Signed. Long-only with long_only=True
Covariance inverse
By blocks, damped by the dials

Hierarchical risk parity is stable and ignores most of the covariance. Minimum variance uses all of it and is fragile. A Schur bridge is a path between the two. At one end it is exactly the heuristic and at the other it is exactly the optimizer.

The idea

Split the assets into clusters. Block inversion writes the minimum-variance direction Σ−11 one cluster at a time. Inside each cluster it is a minimum-variance portfolio on that cluster's covariance conditional on every other asset. Across clusters, the budget is the inverse of that conditional variance.

Hierarchical and clustered heuristics drop the conditioning. The bridge puts it back by degrees, with two dials:

  • gamma conditions each cluster on the assets outside it.
  • eta conditions each asset on the other members of its cluster.

With both dials at 1 the weights equal Σ−11, normalized, for any partition.

The named bridges

Each constructor names its two ends. Both ends are reproduced to machine precision with the default settings.

ConstructorDials at 0Dials at 1
hrp_to_min_variance(gamma)Hierarchical risk parityMinimum variance
hmv_to_min_variance(gamma)Hierarchical minimum varianceMinimum variance
herc_to_min_variance(gamma, eta, n_clusters)Hierarchical equal risk contributionMinimum variance
nco_to_min_variance(gamma, n_clusters)Nested clustered optimizationMinimum variance
inverse_variance_to_min_variance(eta)Inverse varianceMinimum variance

The far end can be a different optimizer. Pass companion="vol" to land on maximum diversification, or companion="mean" to land on the tangency portfolio.

Use

from allocation import SchurBridge

est = SchurBridge.hrp_to_min_variance(gamma=0.5).fit(returns)
est.weights_
est.endpoints_      # ('HRP', 'minimum variance')

SchurBridge.herc_to_min_variance(gamma=0.5, eta=0.5, n_clusters=8)
SchurBridge.nco_to_min_variance(gamma=0.5, n_clusters=8)
SchurBridge.inverse_variance_to_min_variance(eta=0.5)
SchurBridge.hrp_to_min_variance(0.5, companion="vol")     # to max diversification
SchurBridge.hrp_to_min_variance(0.5, long_only=True)      # refuse short positions

Away from the heuristic end the weights can be negative, as minimum-variance weights can. long_only=True caps eta at each cluster's long-only limit and raises ValueError if a short position would remain.

Where the clusters come from

By default the assets are ordered along the Fiedler vector of their correlation graph, and the order is either bisected down to single assets or cut into n_clusters contiguous blocks. The order changes only when two assets' coordinates cross. Pass clusters= to fix the partition yourself, for example by sector.

Everything after the partition is a closed-form, continuous function of the covariance. At the far end the weights do not depend on the partition. So the jump in weights caused by an asset changing cluster shrinks to zero as the dials approach 1.

Parameters

ParameterDefaultMeaning
gamma0.5Conditioning of each cluster on the assets outside it, from 0 to 1.
eta1.0Conditioning of each asset on its cluster mates. 0 holds inverse variance inside a cluster. 1 holds the cluster's minimum-variance portfolio.
n_clustersNoneCut the order into this many contiguous clusters. None bisects down to single assets.
clustersNoneA fixed label per asset. Overrides the spectral ordering.
conditioning"siblings""siblings" conditions each block on its sibling down the tree. "all" conditions each cluster on every other asset, which is exact and costly. "factor" conditions on one portfolio per other cluster, which is exact when cross-cluster dependence runs through one factor per cluster, and scales.
split"dial"How budget is divided between sibling clusters. "dial" starts at hierarchical risk parity. "minvar" starts at hierarchical minimum variance. "hrp" is the rule used by Schur-complementary, which does not reach minimum variance.
outer"stack""optimize" runs a minimum-variance step across clusters, as nested clustered optimization does.
companion"ones"The vector u in the far end Σ−1u: "ones", "vol", "mean", or an array.
long_onlyFalseCap eta to keep weights non-negative, and raise if they still are not.
ridge0.0Regularization added to every block solve.
knn, prior, prior_weightOptions for the ordering: sparsify the similarity graph to nearest neighbours, or blend in a prior similarity such as sectors.
covariance_estimatorNoneAny online estimator with partial_fit and covariance_. None uses an exponentially weighted covariance.
