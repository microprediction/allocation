Schur-complementary

Hierarchical risk parity with a dial toward minimum variance.

Batch
SchurComplementary
Streaming
StreamingSchur
Weights
Long-only, sum to one
Matches
skfolio's SchurComplementary

Hierarchical risk parity splits the budget between two halves of the assets as if the halves were uncorrelated. The Schur-complementary portfolio corrects each half's covariance for its correlation with the other, by an amount gamma.

What it does

At gamma=0 it is hierarchical risk parity exactly. As gamma rises the weights move toward minimum variance. They do not reach it in general. If you need the far end to be exact, use the Schur bridge.

This estimator uses the same formula as skfolio and reproduces its weights to machine precision when given the same asset order. The difference is the order. Here it comes from the Fiedler vector of the correlation graph and not from a dendrogram. The Fiedler vector moves continuously with the covariance, so the order changes only when two coordinates cross. In our experiments that gives lower turnover under streaming updates.

Use

from allocation import SchurComplementary

est = SchurComplementary(gamma=0.5).fit(returns)
est.weights_
est.effective_gamma_     # the gamma actually used (see keep_monotonic)

for batch in stream:
    est.partial_fit(batch)

Parameters

ParameterDefaultMeaning
gamma0.5Coupling between the two halves at each split, from 0 to 1.
keep_monotonicTrueCap gamma at the largest value for which portfolio variance is still falling, as skfolio does. effective_gamma_ reports the value used.
ridge0.0Regularization of the cross-block solve, for blocks that are rank-deficient.
knnNoneSparsify the similarity graph to this many nearest neighbours, for large universes.
prior, prior_weightNone, 0.0A prior similarity matrix, such as sectors, and its weight in the ordering.
covariance_estimatorNoneAny online estimator with partial_fit and covariance_. None uses an exponentially weighted covariance.
halflife60.0Half-life of the default covariance, in observations.

After fitting: weights_, effective_gamma_, order_, fiedler_.
